# Исследование проблемы получения данных из SBIS

## Проблема

При синхронизации товаров из SBIS через прайс-лист 24 (`priceListId: 24`) получаем только **54 товара** из категории "Хоккей на траве", хотя в интерфейсе SBIS в прайс-листе "Новый прайс" отмечено **324 товара** в этой категории.

## Проведенные исследования

### 1. Анализ пагинации

**Используемый подход:**
- Пагинация через `position` и `order` (согласно документации SBIS)
- `pageSize: 1000` (максимальное значение)
- `priceListId: 24` (прайс-лист "Новый прайс")
- `pointId: 201` (точка продаж)

**Результаты:**
- Получено **2303 элемента** (2076 товаров, 227 категорий)
- После дедупликации: **1996 уникальных товаров**
- Распределение по корневым категориям:
  - "Бейсбол и Софтбол": 1942 товара
  - "Хоккей на траве": 54 товара

**Вывод:** Пагинация работает корректно, все страницы получены (4 страницы, последняя страница вернула пустой объект `{}`).

### 2. Анализ атрибута "Вид спорта"

**Статистика по атрибуту "Вид спорта":**
- "Бейсбол": 258 товаров
- "Софтбол": 67 товаров
- "Бейсбол и Софтбол": 43 товара
- "Хоккей на траве": 18 товаров
- "Бейсбол/Софтбол": 6 товаров
- "Бейсбол и софтбол": 1 товар

**Вывод:** Только 18 товаров имеют атрибут "Вид спорта": "Хоккей на траве", но 54 товара привязаны к корневой категории "Хоккей на траве" через `hierarchicalParent`. Это означает, что большинство товаров из "Хоккей на траве" не имеют этого атрибута, но правильно привязаны через иерархию категорий.

### 3. Тестирование различных параметров

#### Тест 1: Смена `pointId` (201 → 169)

**Результат:** Количество товаров не изменилось.

#### Тест 2: Запрос без `priceListId`

**Результат:** 
- Получено меньше товаров (142 вместо 1996)
- Изменилась структура категорий (5 корневых категорий вместо 2)
- Некоторые товары не имеют `hierarchicalParent`

**Вывод:** `priceListId: 24` критически важен для получения правильного набора товаров.

#### Тест 3: Возврат `priceListId: 24`

**Результат:** Вернулись к исходным 1996 товарам.

### 4. Анализ структуры данных

**Корневые категории (Level 0):**
- "Бейсбол и Софтбол" (`hierarchicalId: 15443`)
- "Хоккей на траве" (`hierarchicalId: 13876`)

**Распределение по уровням категорий:**
- Level 0: 3 категории (2 уникальные)
- Level 1: 44 категории
- Level 2: 135 категорий
- Level 3: 41 категория
- Level 4: 4 категории

**Вывод:** Иерархия категорий построена корректно, все товары имеют привязку к корневым категориям.

### 5. Логика привязки товаров к корневым категориям

**Реализованная логика:**
1. Приоритет: `hierarchicalParent` → поиск корневой категории через иерархию
2. Резерв: атрибут "Вид спорта" (если не совпадает с категорией из `hierarchicalParent`)
3. Эвристика: анализ названия товара (для товаров без `hierarchicalParent`)

**Результат:** Все 1996 товаров успешно привязаны к корневым категориям.

## Гипотезы о несоответствии количества товаров

### Гипотеза 1: Товары находятся в других прайс-листах

**Описание:** Товары из "Хоккей на траве" могут быть распределены по нескольким прайс-листам, а не только в прайс-листе 24.

**Проверка:** Требуется запрос к поддержке SBIS для уточнения, какие прайс-листы содержат товары из "Хоккей на траве".

### Гипотеза 2: В прайс-листе 24 действительно только 54 товара

**Описание:** Возможно, в прайс-листе 24 действительно только 54 товара из "Хоккей на траве", а остальные 270 товаров находятся в других прайс-листах или не включены в прайс-лист 24.

**Проверка:** Требуется уточнение в интерфейсе SBIS или запрос к поддержке.

### Гипотеза 3: Проблема с фильтрацией в интерфейсе SBIS

**Описание:** Возможно, в интерфейсе SBIS отображаются товары из нескольких прайс-листов или используется другая логика подсчета.

**Проверка:** Требуется уточнение у поддержки SBIS, как именно считается количество товаров в интерфейсе.

### Гипотеза 4: Товары не опубликованы или скрыты

**Описание:** Возможно, часть товаров имеет `published: false` или скрыты другими параметрами.

**Проверка:** В текущей реализации мы получаем все товары независимо от `published`, поэтому эта гипотеза маловероятна.

## Выводы

1. **Пагинация работает корректно** - все страницы получены, пустые ответы обработаны правильно.

2. **Привязка к корневым категориям работает корректно** - все товары успешно привязаны, используется приоритет `hierarchicalParent` с резервом через атрибут "Вид спорта".

3. **Проблема не в коде синхронизации** - код корректно получает все доступные товары из прайс-листа 24.

4. **Вероятная причина:** Товары из "Хоккей на траве" распределены по нескольким прайс-листам, или в прайс-листе 24 действительно только 54 товара.

## Технические детали

### Используемые параметры запроса

```typescript
{
  pointID: 201,
  priceListId: 24,
  pageSize: 1000,
  withBalance: false,
  withBarcode: true
}
```

### Обработка пагинации

- Первая страница: без `position`
- Последующие страницы: `position = hierarchicalId` последнего элемента, `order = 'after'`
- Остановка: когда `nomenclatures` - пустой массив `[]` или пустой объект `{}`

### Обработка пустых ответов

```typescript
// Если nomenclatures - это пустой объект, преобразуем его в пустой массив
if (typeof nomenclatures === 'object' && nomenclatures !== null && Object.keys(nomenclatures).length === 0) {
  nomenclatures = []
}
```
